Each groove is a straight entry run, a bend of the set radius, and a straight exit run between its two fixed ends. With the two angles set, the knee's position follows, so the ends cannot drift. Knee Z slides the knee along the entry run and swings the exit run to still meet the end. Node spacing divides the result into chart rows, and the status line gives the chord error it costs on the bend. U is the fraction of one index, so the path stretches to fit when the index count changes. C° and ARC are derived from U, the index count and the diameter. Linked rows are fixed by the neighbouring index: B always ends on the next index's top slot, which is what makes N copies close around the barrel. In the real op, the wrapped view will be drawn by executing the generated program, so it cannot disagree with the G-code. Here it is drawn from the chart.
