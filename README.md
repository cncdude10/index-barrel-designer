# Index Barrel Designer

Designs one-way indexing barrel cams (the groove path a spring pin follows so each stroke indexes the
part one station and it cannot drive backwards), and exports the lathe macro program, STL and DXF.

**Install on Android:** open the site in Chrome → menu → *Install app*. It then works with no internet.

This repository is a build product. Do not edit it by hand; it is regenerated from the designer.
